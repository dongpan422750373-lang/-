# 背书 · iPhone 主屏幕版

装完是主屏幕上一个独立图标，全屏打开，没有地址栏，断网能用，数据全在手机里。不用 Mac、不用证书、不会过期。

包里 6 个文件：`index.html`、`sw.js`、`manifest.json`、三个图标。

---

## 一、先把文件放到网上（一次性，约 15 分钟）

iPhone 要求网页必须从 **https 地址**打开，才能装成主屏幕应用并离线运行。所以需要一个免费的静态托管。**只有第一次打开需要联网，之后全靠本地缓存，再也不用连。**

### 推荐：GitHub Pages（免费、永久、https）

1. 去 <https://github.com> 注册账号。
2. 右上角 `+` → **New repository**。仓库名填 `beishu`，选 **Public**，点 Create。
3. 在仓库页点 **Add file → Upload files**，把解压出来的 **6 个文件全部拖进去**（是文件本身，不是文件夹），下拉点 **Commit changes**。
4. 点 **Settings** → 左边 **Pages** → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)` → **Save**。
5. 等一两分钟刷新，页面顶部会出现网址，形如：

   ```
   https://你的用户名.github.io/beishu/
   ```

### 已经装过旧版的，怎么更新

把 `index.html` 和 `sw.js` 两个文件重新传上去覆盖（`sw.js` 里的版本号已经改成 v4 了，手机才知道要换新的）。然后在手机上把应用**完全划掉关闭**，再打开一次，新功能就出来了。

**题目不会丢。** 更新只换代码，题库存在手机本地，不受影响。不放心的话更新前先在「统计 → 导出」存一份。

### 备选

任何能放静态文件的地方都行。国内访问 github.io 偶尔慢，但只影响第一次打开。

## 二、装到主屏幕

1. **用 iPhone 的 Safari 打开**上面那个网址。
   ⚠️ 必须是 Safari。微信内置浏览器、Chrome 都不行，它们没有「添加到主屏幕」这个功能。
2. 等页面完全加载出来（看到「今日」界面，里面有两道示例题）。
3. 点底部中间的**分享按钮**（方框向上箭头）。
4. 往下滑，点 **「添加到主屏幕」** → 右上角「添加」。
5. 回到桌面，图标就在那儿了。点开是全屏的，跟 App 一模一样。

**装好之后再开始正式录题。** iOS 里主屏幕应用和 Safari 的数据是分开存的，先在 Safari 里录的题不一定能带过去。真要搬，用「统计 → 导出」再在应用里「导入」。

## 三、五个页面

**今日**　还剩几题、今天做了多少、按科目分布，最上面一张**段位卡**（第五节）。点「开始复习」进入。

**听背**　读题 → 停一下让你想 → 读答案 → 下一题。走路、坐车、做饭的时候听。四组开关：

| 开关 | 选项 | 说明 |
|---|---|---|
| 按什么顺序 | 按到期先后 / **随机** | 随机是每次重新洗牌。老按同一个顺序背，容易背成"顺口溜"，换个顺序就卡壳，隔几天洗一次能治这个 |
| 听哪些题 | 今天到期的 / 整个题库 | 今天的做完了还想听，就切到整个题库 |
| 读什么 | 题目 + 答案 / 只读题目 | |
| 中间停多久 | 2 / 3 / 5 / 8 秒 / **不自动** | 「不自动」= 停在那儿等你点「继续」，想多久想多久 |

听到哪题没记住，按「这题没记住」就把它丢回今天的队列。

**录题**　题型只有**采分点**一种：题目写在上面，答案拆成一条一条，复习时逐条对勾。下面还有一栏**提示**（第四节）。

「加张截图」可以直接拍照或从相册选刷题软件的截图，会自动压到 1400px 以内再存。

页面顶部还有 **「📷 拍照自动录入」**——选几张截图，自动识别文字、归类、拆采分点、写提示，你过一眼就能入库。要先配识别服务，见第七节。

**题库**　搜索，按科目筛，还有三个快捷筛选：

- **今日录入**——今天新录的题，最新的排最前。录完一批想回头检查有没有录错、有没有漏写采分点，从这儿进
- **待复习**——今天到期的
- **老是错**——忘过两次以上的

点任意一题可以改或删。以前录的挖空卡、问答卡还能照常复习，编辑时会显示「这是一张旧卡」，想统一格式就点一下「转成采分点」，它会自动把答案拆开给你，你再改改。

**统计**　最该回头看的、错因分布、**复习策略**、**到期提醒**、占用空间、备份、字号。

## 四、提示怎么用

以前那栏「知识点」去掉了，换成**提示**。区别是：知识点是给统计看的，提示是给你自己看的。

录题时在「提示」里写**勾得起记忆的线索**，复习时它藏在一个「给点提示」按钮后面，**点了才出来**。想不起来的时候点一下，多半就接上了——这比直接翻答案有用得多，自己捞出来的记得牢。

好的提示长这样：

- `八条。口诀：科理直启，循巩因量。`
- `一共五条。两个口号一前一后，三家企业先军工后民用。`
- `时间锚点：签约在《马关条约》之后第三年。`
- `前三条讲经济，后两条讲思想。`

**别把答案抄进提示**，抄了就没得想了。留空的话按钮不会出现，不影响正常复习。题库列表里带提示的题会标一个 💡。

## 五、段位

**今日**页最上面那张卡就是。点开有大徽章、打卡格和完整规则。

- 六个大段：**青铜 → 白银 → 黄金 → 铂金 → 钻石 → 最强王者**
- 青铜到钻石，每个大段分 **Ⅳ Ⅲ Ⅱ Ⅰ** 四个小段，每个小段 **三颗星**
- **达标一天 +1 颗星**，攒满三颗自动升一小段，四个小段升一个大段
- **一题没做的日子 −1 颗星**，星星扣光就掉一小段
- **做了但没达标：不加不扣**（算你到场了）
- **青铜 Ⅳ 是地板**，最差也就停在那儿，掉不下去
- 到**最强王者**就不看星星了：达标一天 **+10 分**，缺一天 **−10 分**，最低 0 分，不掉段

从零爬到最强王者，要 60 天达标。

**什么叫「达标」**：当天复习的题数 ≥ 每日目标。目标默认 **20 题**，在段位页里能改（改小容易连上，改大升得快）。改动只影响以后，已经结算过的日子不重算。

**结算是打开应用的时候算的。** 断更几天再打开，会把那几天一次性补算上，该扣的扣。所以哪怕当天只做两三题，也比一题不做强——做了就是「不加不扣」，一题没做才扣星。

打卡格的三种颜色：绿=达标、黄=做了没达标、红=一题没做。

## 六、复习是怎么排的

- 三档：**忘了 / 模糊 / 记得**。按钮上直接写着「下次什么时候再见」，比如「10 分钟 / 8 天 / 17 天」。
- 评「忘了」或「模糊」后问一句错因（不会 / 记混 / 看错题）。**标了「记混」的题，下次进队列会被排到最前面，并按知识点聚在一起**，方便左右对比。

「统计 → 复习策略」里有三档遗忘曲线，随时能换，换了立刻生效，只影响之后评的题：

| 策略 | 间隔 | 什么时候用 |
|---|---|---|
| **艾宾浩斯** | 固定阶梯：5 分 → 30 分 → 12 时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天 → 60 天。记得走一格，模糊原地踏步，忘了退回第一格 | 新东西刚上手最灵。代价是头两天同一道题要刷好几遍 |
| **标准**（默认） | 每道题记自己的难易度，记得就指数拉长：1 → 3 → 8 → 20 天…… 难题自动来得勤，简单题自动往后躲 | 日常推进 |
| **宽松** | 比标准再拉长约六成，每天要做的题明显变少 | 题库太大做不完，或者临考只想把重点滚一遍 |

**「忘了」的题当天队尾还会再出现一次**，三种策略都一样。

## 七、到期提醒（能力有限，先说清楚）

「统计 → 到期提醒」可以开通知，设一个每天提醒的时间点。

**它能做到**：应用开着、或者你刚把它打开的时候，到点了会推一条「今天还有 N 题到期」。

**它做不到**：手机锁屏放兜里，它基本**不会响**。iOS 会冻结后台的网页应用，没有服务器推送的话谁也叫不醒它。这是苹果对网页应用的限制，不是设置问题。

所以别把它当闹钟。真想不忘，**每天固定一个时间自己点开一次**更靠谱——比如晚饭后。段位系统某种程度上就是干这个的：断一天掉一颗星，比通知管用。

---

## 八、备份（每周一次）

「统计 → 导出（含图片）」会生成一个 json 文件，iPhone 会弹出分享菜单，存到「文件」App 或直接发给自己。换手机、误删应用之后，装好新的再「导入备份」就全回来了。

「导出（仅文字）」体积小，适合日常快速存一份。

**卸载主屏幕图标会连数据一起删掉，所以备份别偷懒。**

段位、每日目标、策略这些设置存在另一个地方（浏览器的 localStorage），**不在备份文件里**。换手机之后段位要从头攒，题目不会丢。

## 九、自动录题（可选）

选几张刷题截图，自动识别题目、判断科目、拆采分点、写提示，你确认后一键入库。**不配也不影响手动录题。**

### 配置（一次性，约 10 分钟）

**1. 领一个 API Key**

推荐智谱，有免费档：去 <https://bigmodel.cn> 注册 → 右上角进「个人中心 → API Keys」→ 新建，复制那串 key。

**2. 填进应用**

打开应用 →「统计」→ 拉到底「自动录题 · 识别服务」：

- **服务商**：点「智谱」，地址和模型名会自动填好
- **API Key**：粘贴进去
- **思考模式**：保持「关」。付费的旗舰视觉模型默认会先想一段再答，识别截图用不上，关掉省下大约一半输出费用，也快一截。某张图老认不准，再开起来试试
- 点 **保存**，再点 **测试连接**

看到「通了，可以用了」就成了。

**3. 想认得更准，就换付费模型**

免费的 `glm-4.6v-flash` 是 9B 的小模型，遇到大段小字、多栏排版、手写体或者拍歪了的截图，经常漏字串行。把「模型名」改成 **`glm-4.6v`**（106B 旗舰版）就好很多——地址和 Key 都不用动，改一个字段的事。

前提是智谱账号先实名认证并充值。价格是输入 1 元 / 百万 tokens、输出 3 元 / 百万，一张考题截图大概几厘钱，录几百张也就几块钱。先充最低额度，用两天回控制台看一眼实际消耗。

嫌旗舰版慢，中间还有个 `glm-4.6v-flashx`，同样 9B 但走付费通道，速度快、限流松。

**4. 模型名可能要改**

免费型号名字会变。如果报错说模型不存在，去智谱的模型列表页看当前哪个视觉模型是免费的（名字里带 `v` 是视觉模型，带 `flash` 通常是免费档，**带 `flashx` 的是收费的，别选错**），把名字抄进「模型名」那一栏。

### 怎么用

「录题」→ 顶部 **📷 拍照自动录入** → 选截图（可以一次选好几张，会排队处理）。

每张识别完给你一张卡片：科目、题目、采分点（一行一条）、提示。**每一栏都能当场改**，采分点想加想删直接在文本框里改行就行。改好点「存入题库」，不满意点「丢弃」。

### ⚠️ 关于答案，这条最要紧

- 截图里**本身写了答案**的，模型照着拆，直接用。
- 截图里**没写答案**的，模型会自己作答，但会打上黄色的 **「AI 推断 · 未核对」** 标记。

**打了这个标记的，核对过再背。** 历史材料题模型也会答错，一个错答案背熟了比没背更糟。标记会一直跟着这张卡，在复习页和题库列表都看得到——**你手动编辑过一次，标记就自动消失**。

## 十、如果测试连接说「连不上」

多半是浏览器的跨域限制（服务商的接口没允许网页直接调用）。挂一个免费中转就行，五分钟：

1. 注册 <https://dash.cloudflare.com>（免费）
2. 左边 **Workers & Pages** → **Create** → **Create Worker** → 起个名 → Deploy
3. 点 **Edit code**，把里面的内容全删掉，换成下面这段：

```js
export default {
  async fetch(req) {
    const cors = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Headers': '*',
      'Access-Control-Allow-Methods': 'POST, OPTIONS'
    };
    if (req.method === 'OPTIONS') return new Response(null, { headers: cors });

    const target = 'https://open.bigmodel.cn/api/paas/v4/chat/completions';
    const r = await fetch(target, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': req.headers.get('Authorization') || ''
      },
      body: await req.text()
    });
    const out = new Response(r.body, r);
    for (const k in cors) out.headers.set(k, cors[k]);
    return out;
  }
};
```

4. 右上角 **Deploy**，会得到一个形如 `https://xxx.你的名字.workers.dev` 的地址
5. 回应用「统计 → 自动录题」，服务商选 **自定义**，**接口地址**填这个 workers.dev 地址，模型名和 Key 照旧，保存 → 测试连接

（如果换了别家服务商，把上面代码里 `target` 那行的网址改成对应的就行。）

Cloudflare 在国内偶尔会慢。如果实在连不上，手动录题这条路一直是通的，不影响用。

## 十一、改了代码怎么更新

改完 `index.html` 后，**必须把 `sw.js` 第 2 行的版本号加一**：

```js
const V = 'beishu-v5';   // 现在是 v4
```

不改版本号的话，手机会一直用旧的缓存。改完重新上传，手机上把应用完全关掉再打开，就更新了。

几个常改的地方，都在 `index.html` 里：

- 配色 → 开头的 `:root`
- 复习间隔 → `schedule()` 和上面的 `EBB` 数组
- 段位颜色、每段几颗星 → `TIERS` 数组和 `rankUp()` / `rankDown()`
- 徽章形状 → `rankSVG()`
- 缺席扣几颗星 → `settleRank()` 里那句 `rankDown(r)`
- 默认每日目标 → `GOAL_DEFAULT`

## 十二、几个已知限制

- **锁屏会中断朗读。** iOS 会冻结后台的网页脚本。想放兜里听，先去「设置 → 显示与亮度 → 自动锁定」调成「永不」，听完记得调回来。
- **通知叫不醒后台的应用**，见第七节。
- **朗读用的是系统中文语音**，听起来不如专业朗读软件自然，但读知识点够用了。第一次点播放可能有半秒延迟，是系统在加载语音。
- 图片存在手机本地，导出「仅文字」的备份里不含图片，重要的截图建议在相册里也留一份。
- **自动录题要联网**，其余功能（复习、听背、录题、段位、备份）全部离线可用。
- 苹果对网页应用有存储配额，几百道带图的题一般没问题，「统计」页顶部能看到已占用多少。
