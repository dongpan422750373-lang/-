# 背书 · iPhone 主屏幕版

装完是主屏幕上一个独立图标，全屏打开，没有地址栏，断网能用，数据全在手机里。不用 Mac、不用证书、不会过期。

包里 6 个文件：`index.html`、`sw.js`、`manifest.json`、三个图标。

---

## 一、先把文件放到网上（一次性，约 15 分钟）

iPhone 要求网页必须从 **https 地址**打开，才能装成主屏幕应用并离线运行。所以需要一个免费的静态托管。**只有第一次打开需要联网，之后全靠本地缓存，再也不用连。**

### 推荐：GitHub Pages（免费、永久、https）

1. 去 <https://github.com> 注册账号。
2. 右上角 `+` → **New repository**。仓库名填 `beishu`，选 **Public**，点 Create。
3. 在仓库页点 **Add file → Upload files**，把解压出来的 **6 个文件全部拖进去**（是文件本身，不是文件夹），下拉点 **Commit changes**。
4. 点 **Settings** → 左边 **Pages** → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)` → **Save**。
5. 等一两分钟刷新，页面顶部会出现网址，形如：

   ```
   https://你的用户名.github.io/beishu/
   ```

### 备选

任何能放静态文件的地方都行。国内访问 github.io 偶尔慢，但只影响第一次打开。

## 二、装到主屏幕

1. **用 iPhone 的 Safari 打开**上面那个网址。
   ⚠️ 必须是 Safari。微信内置浏览器、Chrome 都不行，它们没有「添加到主屏幕」这个功能。
2. 等页面完全加载出来（看到「今日」界面，里面有两道示例题）。
3. 点底部中间的**分享按钮**（方框向上箭头）。
4. 往下滑，点 **「添加到主屏幕」** → 右上角「添加」。
5. 回到桌面，图标就在那儿了。点开是全屏的，跟 App 一模一样。

**装好之后再开始正式录题。** iOS 里主屏幕应用和 Safari 的数据是分开存的，先在 Safari 里录的题不一定能带过去。真要搬，用「统计 → 导出」再在应用里「导入」。

## 三、五个页面

**今日**　还剩几题、今天做了多少、按科目分布。点「开始复习」进入。

**听背**　**这是小程序版做不了的功能。** 读题 → 停几秒让你想 → 读答案 → 自动下一题。走路、坐车、做饭的时候听。可以只读题目，停顿时长 2/3/5/8 秒可调，听到哪题没记住，按「这题没记住」就把它丢回今天的队列。

**录题**　三种题型：

| 类型 | 用在哪 | 怎么写 |
|---|---|---|
| 挖空复述 | 口号、条款、时间、人名这类要精确记的 | 用 `【】` 包住要盖掉的字。选中一段文字再按「插入【】挖空」，会直接包上 |
| 问答 | 一问一答 | 正面问题，背面答案 |
| 采分点 | 科目二简答、论述 | 一条一个点，复习时逐条点亮 |

「加张截图」可以直接拍照或从相册选刷题软件的截图，会自动压到 1400px 以内再存。

**题库**　搜索、按科目筛、「老是错」筛出忘过两次以上的。点任意一题可以改或删。

**统计**　最该回头看的知识点、错因分布、占用空间、备份、字号（小/中/大/特大）。

---

## 四、复习是怎么排的

- 三档：**忘了 / 模糊 / 记得**。按钮上直接写着「下次什么时候再见」，比如「10 分钟 / 8 天 / 17 天」。
- **忘了** → 间隔清零，**当天队尾还会再出现一次**，同时降低这道题的易度。
- **模糊** → 间隔只小幅拉长。
- **记得** → 指数拉长：1 天 → 3 天 → 8 天 → 20 天……
- 评「忘了」或「模糊」后问一句错因（不会 / 记混 / 看错题）。**标了「记混」的题，下次进队列会被排到最前面，并按知识点聚在一起**，方便左右对比。

---

## 五、备份（每周一次）

「统计 → 导出（含图片）」会生成一个 json 文件，iPhone 会弹出分享菜单，存到「文件」App 或直接发给自己。换手机、误删应用之后，装好新的再「导入备份」就全回来了。

「导出（仅文字）」体积小，适合日常快速存一份。

**卸载主屏幕图标会连数据一起删掉，所以备份别偷懒。**

---

## 六、改了代码怎么更新

改完 `index.html` 后，**必须把 `sw.js` 第 2 行的版本号加一**：

```js
const V = 'beishu-v2';   // 原来是 v1
```

不改版本号的话，手机会一直用旧的缓存。改完重新上传，手机上把应用完全关掉再打开，就更新了。

配色在 `index.html` 开头的 `:root` 里；复习间隔在 `schedule()` 函数里。

## 七、几个已知限制

- **锁屏会中断朗读。** iOS 会冻结后台的网页脚本。想放兜里听，先去「设置 → 显示与亮度 → 自动锁定」调成「永不」，听完记得调回来。
- **朗读用的是系统中文语音**，听起来不如专业朗读软件自然，但读知识点够用了。第一次点播放可能有半秒延迟，是系统在加载语音。
- 图片存在手机本地，导出「仅文字」的备份里不含图片，重要的截图建议在相册里也留一份。
- 苹果对网页应用有存储配额，几百道带图的题一般没问题，「统计」页顶部能看到已占用多少。
