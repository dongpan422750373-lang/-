# 背书 · iPhone 主屏幕版

装完是主屏幕上一个独立图标，全屏打开，没有地址栏，断网能用，数据全在手机里。不用 Mac、不用证书、不会过期。

包里有 6 个核心 App 文件：`index.html`、`sw.js`、`manifest.json`、三个主屏幕图标；`assets/ranks` 里另有 6 张 Riot 官方段位徽章，并带说明书和 Windows 一键发布工具。

v12 新增：青铜、白银、黄金、铂金、钻石、最强王者改用 Riot 官方原始徽章；备份会连段位、每日目标、倒计时、提醒、字号和 API Key 一起保存；统计页可设置每日背书提醒，并可生成 iPhone 系统日历提醒。

## 一、先把文件放到网上（一次性，约 15 分钟）

iPhone 要求网页必须从 **https 地址**打开，才能装成主屏幕应用并离线运行。所以需要一个免费的静态托管。**只有第一次打开需要联网，之后全靠本地缓存，再也不用连。**

### 推荐：GitHub Pages（免费、永久、https）

1. 去 <https://github.com> 注册账号。
2. 右上角 `+` → **New repository**。仓库名填 `beishu`，选 **Public**，点 Create。
3. 在仓库页点 **Add file → Upload files**，把解压后 `beishu-ios` 文件夹里的**全部内容**拖进去（包括 `assets` 文件夹），下拉点 **Commit changes**。
4. 点 **Settings** → 左边 **Pages** → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)` → **Save**。
5. 等一两分钟刷新，页面顶部会出现网址，形如：

   ```
   https://你的用户名.github.io/beishu/
   ```

### 已经装过旧版的，怎么更新

#### 最省事：Windows 一键发布

本压缩包已经绑定仓库 `dongpan422750373-lang/-`。解压后双击 **`一键发布更新.bat`**：

1. 第一次运行如果电脑没有 Git，脚本会打开安装页面；装好后重新双击。
2. 第一次推送时浏览器会要求登录 GitHub，登录一次即可。
3. 以后收到新版压缩包，解压后双击这个按钮，等待提示「发布完成」即可。

v10 起，iPhone App 联网打开时会自动检查并切换新版。通常不需要再改网址、清缓存或反复关闭；若没有及时变化，进入「统计」点 **立即检查更新**。

#### 手动上传（备用）

仍可把新版文件上传到仓库根目录覆盖；v12 还要把 `assets` 文件夹一起上传。`sw.js` 已升级为 v12，发布后 App 会自动处理旧缓存。

**题目、段位、提醒和 API Key 都不会丢。** 同一个网址更新只换代码，数据仍存在手机本地。不放心的话更新前在「统计 → 导出」存一份；v12 的备份也会把这些设置一起带上。

以前录的题也照常能用：老的采分点是一行行的纯文字，这版多了「小点」这一层，老题目不受影响，想细分的时候进去编辑加就行。

### 备选

任何能放静态文件的地方都行。国内访问 github.io 偶尔慢，但只影响第一次打开。

## 二、装到主屏幕

1. **用 iPhone 的 Safari 打开**上面那个网址。
   ⚠️ 必须是 Safari。微信内置浏览器、Chrome 都不行，它们没有「添加到主屏幕」这个功能。
2. 等页面完全加载出来（看到「今日」界面，里面有两道示例题）。
3. 点底部中间的**分享按钮**（方框向上箭头）。
4. 往下滑，点 **「添加到主屏幕」** → 右上角「添加」。
5. 回到桌面，图标就在那儿了。点开是全屏的，跟 App 一模一样。

**装好之后再开始正式录题。** iOS 里主屏幕应用和 Safari 的数据是分开存的，先在 Safari 里录的题不一定能带过去。真要搬，用「统计 → 导出」再在应用里「导入」。

## 三、五个页面

**今日**　还剩几题、今天做了多少、按科目分布，并可设置一个「距离某目标还有多少天」的倒计时。下方有**段位卡**（第七节）。点「开始复习」进入。

**听背**　读题 → 停一下让你想 → 读答案 → 下一题。走路、坐车、做饭的时候听。四组开关：

| 开关 | 选项 | 说明 |
|---|---|---|
| 按什么顺序 | 按到期先后 / **随机** | 随机是每次重新洗牌。老按同一个顺序背，容易背成"顺口溜"，换个顺序就卡壳，隔几天洗一次能治这个 |
| 听哪些题 | 今天到期的 / 整个题库 | 今天的做完了还想听，就切到整个题库 |
| 读什么 | 题目 + 答案 / 只读题目 | 有小点的采分点会连着读，形如「军事工业：江南制造总局，福州船政局」 |
| 中间停多久 | 2 / 3 / 5 / 8 秒 / **不自动** | 「不自动」= 停在那儿等你点「继续」，想多久想多久 |

「上一题」和「下一题」在播放键左右，切换后会自动开始朗读。忘了时可以点「提示」查看录题时填写的线索，也可以点「查看答案」直接核对；听到哪题没记住，按「这题没记住」就把它丢回今天的队列。

**录题**　题型只有**采分点**一种：题目写在上面，答案拆成一条一条，复习时逐条对勾。归类见第四节，采分点怎么拆见第五节，最下面还有一栏**提示**（第六节）。

「加张截图」可以直接拍照或从相册选刷题软件的截图，会自动压到 1400px 以内再存。手动添加的图片题仍然保留；自动录题的原图只用于识别和核对，存题后不会显示，也不会跟着题目保存。

页面顶部还有 **「📷 拍照自动录入」**——选几张截图，自动识别文字、归类、拆采分点、写提示，你过一眼就能入库。要先配识别服务，见第九节。

**题库**　搜索（题干、考点、采分点、小点都能搜到），按科目筛，科目下面还有一排**考点**可以再筛一层。另有三个快捷筛选：

- **今日录入**——今天新录的题，最新的排最前。录完一批想回头检查有没有录错、有没有漏写采分点，从这儿进
- **待复习**——今天到期的
- **老是错**——忘过两次以上的

每条显示「科目 · 考点」和采分点数量（带小点的写成「3 个采分点（含 5 个小点）」）。点任意一题可以改或删。以前录的挖空卡、问答卡还能照常复习，编辑时会显示「这是一张旧卡」，想统一格式就点一下「转成采分点」，它会自动把答案拆开给你，你再改改。

**统计**　最该回头看的、错因分布、**复习策略**、背书提醒、占用空间、备份、字号。

## 四、归到哪里

录题页最上面那一栏，分两层：

- **科目**——大类。可以直接打字改，不再是固定的下拉菜单。写一个新的（比如「历史课标」「教育法规」）它就记住了，下次出现在胶囊里
- **考点 · 子项**——细一层，比如「洋务运动」「教学原则」「罗马法」。可以留空

两栏都**默认接着上一道题**。连着录同一章的题，录完一道下一道自动还停在那个科目、那个考点上，不用每次重选。就算本地的「上次录入」记忆丢了，或刚导入备份，也会从题库最新一题恢复。

归类卡顶部的**「最近归类」**会列出最近用过的几组「科目 · 子项」，点一下就整组填入。科目和子项的输入框都可以自由修改；输入框底下那排胶囊是单项历史值，考点的胶囊只列当前科目下用过的，再点一下取消。

科目和考点胶囊右侧都有 **×**，可以删除不再使用或误录的分类选项。这里删除的只是选择项，已有题目不会被删，仍能从题库「全部」中找到；以后重新输入同名分类就会恢复。

写了考点之后有三个好处：

1. **题库能按考点单独筛**，复习某一章的时候直接调出来
2. **统计里「最该回头看的」精确到考点**，能看出是哪个知识点在漏，而不是笼统一句「中国近代史」
3. **标了「记混」的题按考点聚在一起**排进队列，方便左右对比

不想分那么细就留空，一切照旧。

## 五、采分点与小点

答案拆成一条条采分点，复习时逐条对勾。**每条采分点底下还能再录入子项**——点「＋ 给第 N 条添加子项」，缩进的输入框就出来了，想加几条加几条。子项输入框里按回车，还会紧接着新增下一个。

什么时候值得拆：一条采分点里其实是并列的好几样东西。比如

```
两个口号
  · 前期：自强
  · 后期：求富
军事工业
  · 江南制造总局
  · 福州船政局
  · 安庆内军械所
民用工业：轮船招商局
```

比起摊平成七条平行的采分点，这样分层更接近答题时脑子里的结构：先想起有三块，再往每块底下捞细节。

复习时小点缩在主点下面，**可以单独打勾**。主点旁边显示这条命中了几个小点（`2/3`）。点主点会把它底下的小点一起点亮或一起熄灭；小点全勾上了，主点自动亮。最底下的「命中 X / Y」按主点数算。

拆不出来的就别硬拆，直接写一句话，跟以前一样。

## 六、提示怎么用

录题时在「提示」里写**勾得起记忆的线索**，复习时它藏在一个「给点提示」按钮后面，**点了才出来**。想不起来的时候点一下，多半就接上了——这比直接翻答案有用得多，自己捞出来的记得牢。

好的提示长这样：

- `八条。口诀：科理直启，循巩因量。`
- `一共三块。两个口号一前一后，企业先军工后民用。`
- `时间锚点：签约在《马关条约》之后第三年。`
- `前三条讲经济，后两条讲思想。`

**别把答案抄进提示**，抄了就没得想了。留空的话按钮不会出现，不影响正常复习。题库列表里带提示的题会标一个 💡。

## 七、段位

**今日**页最上面那张卡就是。点开有大徽章、打卡格和完整规则。

- 六个大段：**青铜 → 白银 → 黄金 → 铂金 → 钻石 → 最强王者**
- 青铜到钻石，每个大段分 **Ⅳ Ⅲ Ⅱ Ⅰ** 四个小段，每个小段 **三颗星**
- **达标一天 +1 颗星**，攒满三颗自动升一小段，四个小段升一个大段
- **一题没做的日子 −1 颗星**，星星扣光就掉一小段
- **做了但没达标：不加不扣**（算你到场了）
- **青铜 Ⅳ 是地板**，最差也就停在那儿，掉不下去
- 到**最强王者**就不看星星了：达标一天 **+10 分**，缺一天 **−10 分**，最低 0 分，不掉段

从零爬到最强王者，要 60 天达标。

徽章使用 Riot Developer Portal 提供的 `ranked-emblems-latest.zip` 原始图片，本地打包在 `assets/ranks`，所以断网也能显示。来源：<https://developer.riotgames.com/docs/lol>。League of Legends 与 Riot Games 为 Riot Games, Inc. 的商标；本个人工具与 Riot Games 无隶属或赞助关系。

**什么叫「达标」**：当天复习的题数 ≥ 每日目标。目标默认 **20 题**，在段位页里能改（改小容易连上，改大升得快）。改动只影响以后，已经结算过的日子不重算。

**结算是打开应用的时候算的。** 断更几天再打开，会把那几天一次性补算上，该扣的扣。所以哪怕当天只做两三题，也比一题不做强——做了就是「不加不扣」，一题没做才扣星。

打卡格的三种颜色：绿=达标、黄=做了没达标、红=一题没做。

### 每日背书提醒

进入「统计 → 背书提醒」，选择时间后点 **保存并开启**。从主屏幕打开的 iPhone App 会请求通知权限；App 正在打开时，到点会直接发网页通知，过了时间再打开也会补提醒。当天已经完成每日目标就不再催。

网页 App 被完全关闭或锁屏后，iOS 不会让它继续运行本地定时器。要保证锁屏也准点提醒，再点 **添加到 iPhone 日历**：

1. 生成 `背书提醒-每天xxxx点.ics` 后，打开这个文件。
2. 点右上角 **添加**，保存为每天重复的日历事件。
3. 以后即使背书 App 没打开，iPhone 日历也会在设定时间提醒。

改时间后重新生成一次；若系统保留了旧事件，到日历里删掉旧的「背书时间到了」即可。

## 八、复习是怎么排的

- 三档：**忘了 / 模糊 / 记得**。按钮上直接写着「下次什么时候再见」，比如「10 分钟 / 8 天 / 17 天」。
- 评「忘了」或「模糊」后问一句错因（不会 / 记混 / 看错题）。**标了「记混」的题，下次进队列会被排到最前面，并按考点聚在一起**，方便左右对比。

「统计 → 复习策略」里有三档遗忘曲线，随时能换，换了立刻生效，只影响之后评的题：

| 策略 | 间隔 | 什么时候用 |
|---|---|---|
| **艾宾浩斯** | 固定阶梯：5 分 → 30 分 → 12 时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天 → 60 天。记得走一格，模糊原地踏步，忘了退回第一格 | 新东西刚上手最灵。代价是头两天同一道题要刷好几遍 |
| **标准**（默认） | 每道题记自己的难易度，记得就指数拉长：1 → 3 → 8 → 20 天…… 难题自动来得勤，简单题自动往后躲 | 日常推进 |
| **宽松** | 比标准再拉长约六成，每天要做的题明显变少 | 题库太大做不完，或者临考只想把重点滚一遍 |

**「忘了」的题当天队尾还会再出现一次**，三种策略都一样。

## 九、自动录题（可选）

选几张刷题截图，自动识别题目、判断科目和考点、拆采分点、写提示，你确认后一键入库。**不配也不影响手动录题。**

### 配置（一次性，约 10 分钟）

**1. 领一个 API Key**

推荐智谱，有免费档：去 <https://bigmodel.cn> 注册 → 右上角进「个人中心 → API Keys」→ 新建，复制那串 key。

**2. 填进应用**

打开应用 →「统计」→ 拉到底「自动录题 · 识别服务」：

- **服务商**：点「智谱」，地址和 `glm-4.6v` 模型名会自动填好。它是付费视觉模型；要试免费档，请按智谱控制台当时提供的视觉模型名手动替换
- **API Key**：粘贴进去
- **思考模式**：保持「关」。付费的旗舰视觉模型默认会先想一段再答，识别截图用不上，关掉省下大约一半输出费用，也快一截。某张图老认不准，再开起来试试
- 点 **保存**，再点 **测试连接**

看到「通了，可以用了」就成了。

**3. 默认优先识别准确率**

这个版本默认填入 **`glm-4.6v`**，更适合大段小字、手写体、拍歪的页面，以及“一、二、三”下面还有“1、2、3”的层级。它需要智谱账号开通付费；实际价格和可用免费型号以控制台为准。

**4. 模型名可能要改**

免费型号名字会变。如果报错说模型不存在，去智谱的模型列表页看当前哪个视觉模型是免费的（名字里带 `v` 是视觉模型，带 `flash` 通常是免费档，**带 `flashx` 的是收费的，别选错**），把名字抄进「模型名」那一栏。

### 怎么用

「录题」→ 顶部 **📷 拍照自动录入** → 选截图（可以一次选好几张，会排队处理）。

每张识别完给你一张卡片：科目、考点、题目、采分点、提示。**每一栏都能当场改**；科目和考点既能直接打字，也能点下面已有的分类选项。原截图只在确认卡片中显示，点「存入题库」后会自动删除。采分点是一行一条；**要把某条再拆细，就在它下面另起一行、行首空两格或者打个「·」**，那一行就变成上一条的小点：

```
军事工业
  · 江南制造总局
  · 福州船政局
民用工业：轮船招商局
```

自动识别会把 `一、二、三`、`（一）（二）（三）`、`1. 2. 3.`、`(1)(2)(3)`、`①②③` 等编号当成结构标记。第二套编号如果缩进在某个主项下面，会自动进入该主项的小点，不会和主项并列。

改好点「存入题库」，不满意点「丢弃」。

### ⚠️ 关于答案，这条最要紧

- 截图里**本身写了答案**的，模型照着拆，直接用。
- 截图里**没写答案**的，模型会自己作答，但会打上黄色的 **「AI 推断 · 未核对」** 标记。

**打了这个标记的，核对过再背。** 历史材料题模型也会答错，一个错答案背熟了比没背更糟。标记会一直跟着这张卡，在复习页和题库列表都看得到——**你手动编辑过一次，标记就自动消失**。

## 十、如果测试连接说「连不上」

多半是浏览器的跨域限制（服务商的接口没允许网页直接调用）。挂一个免费中转就行，五分钟：

1. 注册 <https://dash.cloudflare.com>（免费）
2. 左边 **Workers & Pages** → **Create** → **Create Worker** → 起个名 → Deploy
3. 点 **Edit code**，把里面的内容全删掉，换成下面这段：

```js
export default {
  async fetch(req) {
    const cors = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Headers': '*',
      'Access-Control-Allow-Methods': 'POST, OPTIONS'
    };
    if (req.method === 'OPTIONS') return new Response(null, { headers: cors });

    const target = 'https://open.bigmodel.cn/api/paas/v4/chat/completions';
    const r = await fetch(target, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': req.headers.get('Authorization') || ''
      },
      body: await req.text()
    });
    const out = new Response(r.body, r);
    for (const k in cors) out.headers.set(k, cors[k]);
    return out;
  }
};
```

4. 右上角 **Deploy**，会得到一个形如 `https://xxx.你的名字.workers.dev` 的地址
5. 回应用「统计 → 自动录题」，服务商选 **自定义**，**接口地址**填这个 workers.dev 地址，模型名和 Key 照旧，保存 → 测试连接

（如果换了别家服务商，把上面代码里 `target` 那行的网址改成对应的就行。）

Cloudflare 在国内偶尔会慢。如果实在连不上，手动录题这条路一直是通的，不影响用。

## 十一、备份（每周一次）

「统计 → 导出（含图片）」会生成一个 json 文件，存到「文件」App 或发给自己。换手机、误删应用之后，装好新的再「导入备份」就全回来了。

「导出（仅文字）」体积小，适合日常快速存一份。

**卸载主屏幕图标会连数据一起删掉，所以备份别偷懒。**

v12 起，备份会同时保存：**段位和打卡记录、每日目标、复习策略、首页倒计时、背书提醒、字号、归类记录、识别服务配置和 API Key**。旧版 v1 备份仍可正常导入，只是旧文件本身没有这些设置。

因为备份里含 API Key，**只能存给自己，不要发到群里或交给别人**。如果 Key 曾经外泄，应立即去对应服务商控制台删除并重新创建。

## 十二、改了代码怎么更新

改完 `index.html` 后，仍要把 `sw.js` 第 2 行的版本号加一：

```js
const V = 'beishu-v12';   // 现在是 v12，下次改时加到 v13
```

双击包里的 `一键发布更新.bat` 即可提交到已绑定的 GitHub 仓库。v12 会在联网启动时优先读取最新页面，并自动替换旧缓存；「统计」页也有手动检查按钮。

几个常改的地方，都在 `index.html` 里：

- 配色 → 开头的 `:root`
- 内置科目列表 → `SUBJECTS` 数组（不改也行，录题时直接打字就能加新科目）
- 采分点 / 小点的数据结构 → `ptObj()`、`ptPack()` 那几个小函数
- 复习间隔 → `schedule()` 和上面的 `EBB` 数组
- 段位顺序、每段几颗星 → `TIERS` 数组和 `rankUp()` / `rankDown()`
- 段位徽章图片 → `assets/ranks` 和 `TIERS` 数组
- 缺席扣几颗星 → `settleRank()` 里那句 `rankDown(r)`
- 默认每日目标 → `GOAL_DEFAULT`

## 十三、几个已知限制

- **锁屏会中断朗读。** iOS 会冻结后台的网页脚本。想放兜里听，先去「设置 → 显示与亮度 → 自动锁定」调成「永不」，听完记得调回来。
- **网页通知不能在 App 完全关闭后靠本地定时器准点触发。** 锁屏也要可靠提醒，请使用「统计 → 背书提醒 → 添加到 iPhone 日历」。
- **朗读用的是系统中文语音**，听起来不如专业朗读软件自然，但读知识点够用了。第一次点播放可能有半秒延迟，是系统在加载语音。
- 图片存在手机本地，导出「仅文字」的备份里不含图片，重要的截图建议在相册里也留一份。
- **自动录题要联网**，其余功能（复习、听背、录题、段位、备份）全部离线可用。
- 苹果对网页应用有存储配额，几百道带图的题一般没问题，「统计」页顶部能看到已占用多少。
